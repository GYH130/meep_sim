# 相对原项目的进展：验证约束与诊断增强，目标尺寸规律尚未取得

报告日期：2026年9月12日。计算证据截至9月10日；9月12日只复核文件与软件测试，没有启动新一轮结构求解。

## 结论

本阶段有实质性工程进展，但**没有完成比原项目更充分的目标结构光学验证，也没有得到新的可信尺寸规律**。适合合入原项目的是材料审计、拟合证据、明确的盲槽几何语义、失败隔离和回归测试；不适合合入的是“目标结构已验证”“r24已合格”“正式发射率约0.156”等结论。

最有价值的三个新增结果：

- **材料模型的不确定性被定量分离。** 相同10 μm平面适配设置下，内置Ti与Ordal拟合模型的吸收率分别约0.071780和0.037466，差约0.034314。这是材料模型差异，不应记为求解器退步。
- **稳定性问题有了直接的单因素证据。** 相同目标结构的早期测试中，开启材料平均出现NaN/Inf，关闭平均可运行至模拟时间150。但这只证明该设置下的早期改善，没有证明长期收敛和界面精度。
- **平面验证范围扩展到18个独立条件。** 三波长、三观察角、两偏振的历史平面结果全部满足该轮记录的通过条件；最大解析R误差0.007478、独立吸收差0.000354。目标斜槽仍未通过，平面资格不能自动转移。

## 3. 不能把适配对照说成求解器全面超过旧版

原D00在有效Ti波长内最大反射误差约0.001655；原D04在10 μm的平面体吸收差为0.00022483。原D04斜槽还已有A_flux=0.111265、A_volume=0.111417的结果。这些是真正的已有数值成果，不应因旧报告门槛较宽而全部否定。

本阶段10 μm D04普通源适配结果：R=0.92822037，A_flux=0.07177963；解析R误差0.00128647，体吸收差5.1153e-7。普通源和本征模源的两个D00、两个D04适配点均通过其对照门槛。

这表明新实现**至少恢复了这一平面单点的可信结果**，且在此配置下积分差更小；但不是“全波段精度提升若干倍”。旧D00是21频点宽带，本轮适配是单点，历史源带宽、停止设置并非完全一致；积分离散处理也可能影响差值。对应数值见[原D00表](evidence/legacy_D00_flat_ti_fresnel_validation.json)、[原D04表](evidence/legacy_D04_absorbed_power_integrals.json)、[新适配对照](evidence/legacy_comparison.json)。

原项目已经承认D03中Hz斜槽r32相对r48最大吸收差约0.08343；部分PML等项目只有一个取值，与自身比较得到零差，不能视为独立收敛。原D04门槛为1.0，但实际平面差仅0.00022483；应分别评价“验收门槛太松”与“实测结果是否差”。

## 4. 材料路线是最明确的新增交付

内置Ti审计记录有效频率0.08065817–4.83933411 μm⁻¹，对应波长0.20664–12.398 μm；最高Lorentz共振频率15.67135256 μm⁻¹。程序按q=πf_max·Courant/resolution计算粗筛值。r2、Courant=0.5时q=12.308，必须拒绝时域启动，不能把这种设置用于正式材料计算。此条件通过也不等于FDTD已合格，未通过删除高频振子绕过它。完整振子参数见[审计快照](evidence/builtin_ti_audit.json)。

Ordal拟合覆盖6–16 μm，固定介电常数尺度归一化后：

- 301点插值评价网格：NRMSE=0.2688%，最大误差=0.7598%。
- 6个原始节点：NRMSE=0.2780%，最大误差=0.5227%。
- 评价带内最小Im(ε)=50.726，为正；来源、插值与归一化方法存档。

301点不是301次独立测量。该拟合通过既定2%/5%误差门槛，但温度未确证，不是高温或实际加工样品验证。上述量是**复介电常数固定尺度误差**，不能改写成n、k各自相对误差。[拟合记录](evidence/fit_report.json)

同一D04适配设置中，内置Ti与拟合模型吸收率差约3.43个百分点，已经足以影响对低发射率结构的判断。因此后续报告必须标明模型，不能将跨材料差异归因于几何。[材料对照](evidence/material_comparison.json)

## 5. 平面通过18条件，仍不是当前目标斜槽的通行证

历史汇总按条件名去重后为18个平面条件，而非把重复运行计为36个：λ=8.5、10.5、12.0 μm；观察角−60°、0°、+60°；s/p。记录中18项passed为True；最大R/A解析绝对差约0.007478，T差2.34e-9，独立吸收差0.00035392。

这些结果对应各自保存配置及实现。随后改变材料平均、Courant或代码指纹时，不能不经复核就声称旧资格覆盖新设置；该集合也没有覆盖±75°、整个波段及目标槽的镜像/网格收敛。[去重方法与汇总](evidence/review_summary.json)

## 6. 稳定性改善有证据，长期合格仍没有证据

早期单因素对照中，材料平均开启时状态为“fields are NaN or Inf”；关闭时完成早期运行，但status仍明确qualified=false，源尚未结束。这是值得移植的回归用例，不是“关闭平均即可生产”的通用结论。[开启状态](evidence/averaging_on_status.json) · [关闭状态](evidence/averaging_off_status.json)

9月10日目标斜槽长运行仍以wall_timeout/output_incomplete结束，计时14400.20秒，进程树峰值1034.67 MiB。最后日志到模拟时间1650，源结束1050，未达到计划的源后3500。快照留下了诊断通量，但没有完成A_vol和分阶闭合。

本轮最具体的工作流修复是：失败前开始保存定期通量，不再只留下“超时”二字。它让我们能区分目标频率累计通量较平稳与时域尾场未衰减；二者不能互相替代。[终止记录](evidence/tail_result.json)

对设备的判断也应收窄：目前证据支持“**现有串行实现与设置不适合本机高效扫描**”，不支持“设备在物理上无法求解该二维模型”。本例未发生内存超限，没有MPI加速比或性能剖析，尚不能把效率问题全部归给硬件。上一次把90×4小时算成15天，只是串行占用情景，不是合格完成时间预测。
