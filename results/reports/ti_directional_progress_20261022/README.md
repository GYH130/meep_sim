## 当前能支持的主要判断

1. H120、10.5 μm 法向下，1/2/3 μm 填充的模态吸收约为 36.4% / 31.3% / 36.95%，非单调关系；3 μm 是工作候选，不是带内最优证明。
2. H120 相对 H80 在 10.5 μm、15°、p 输入下高约 8.85 个百分点；但高度也改变壁面倾角和填充顶部面积，不能作孤立因果结论。
3. 已有角度采样支持继续探索近法向较高吸收的候选；尚不足以计算全波 8–13 μm 带内角锥指标、FWHM 或完整三维发射瓣。
4. 端口吸收与独立损耗较接近，但净通量与损耗仍有偏差。保存场显示对截面位置敏感；这支持诊断假设，并未唯一确定根因或消除误差。

## 数值、材料和指标约定

- JSON 的 A、R 与绝对差均为无量纲小数。表格/图可显示百分数；“百分点”是绝对差乘 100。
- `A_port = 1 - R_total`；`A_loss_total = A_film + A_Ti_H`；`A_flux` 为原定义的净通量吸收。三者并列保留，不用其中一项覆盖另一项。
- 探索绝对容差 0.005、相对吸收 2%；原 0.002 严格诊断仍保留。允许带通量警告继续探索，不等于通过或正式合格。
- 三维模型使用公开光学钛与 Kischkat SiO₂ 数据。膜为腔底 1/2/3 μm 填充，非全壁等厚涂层；上壁和台面仍为裸钛。
- 射线 M2 的 α=0.9 灰体活性面与真实 SiO₂ 填充不是同一材料模型。523 K 仅用于射线谱权重，不是实测高温光学常数。
- SiO₂ 光学数据有效范围 1.53846–14.28571 μm，禁止直接外推到 20 μm。Ti 表与 SiO₂ 原数据及来源见 [材料目录](data/materials/) 和 [输入清单](data/material_inputs.json)。
- 尚未完成：三维网格收敛、全波连续 8–13 μm 光谱/完整角域积分、实测 TA2/氧化层/粗糙度与温度验证。模型结果不能称为 TA2 实测性能。
