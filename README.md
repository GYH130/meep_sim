# Meep Sim — 金属微结构中红外发射率正问题建模

## 研究对象
飞秒激光加工得到的金属表面微结构（光栅、微柱、凹坑等周期/准周期结构），
目标是在 **8–13 μm 大气窗口** 内实现 **高发射率** 与 **定向发射** 的设计与解释。

## 阶段规划
- **当前阶段（Step 0 – Step N）**：使用 Meep（FDTD）构建可靠的 **正问题模型**：
  给定微结构几何参数 + 材料色散 → 输出
  - 光谱发射率 ε(λ)；
  - 角分辨发射率 ε(λ, θ, φ, 偏振)。
  本阶段重点是 **可复现性、物理自检、参数清晰**，不追求高性能。
- **后续阶段**：
  - 与红外光谱实验数据（FTIR、角分辨发射率）做交叉验证；
  - 在正问题模型基础上接入机器学习（代理模型 / 反问题 / 优化设计）。

## 单位约定
- 所有长度统一使用 **微米 (μm)**。
- Meep 内部为无量纲单位，本项目固定取特征长度 `a = 1 μm`，因此：
  - `length_meep = length_um`
  - `f_meep = a / λ = 1 / λ[μm]`（例如 λ = 10 μm → f = 0.1）
  - `t_meep = t · c / a`
- 频率 / 波长换算工具集中在 `src/materials.py` 与 `src/io_utils.py`。

## 物理假设（默认；脚本中可覆盖并必须显式说明）
- 金属一般近似为 **半无限不透明基底**（厚度足够大，下表面透射可忽略）。
- 在不透明假设下，用 **吸收率 A(λ, θ)** 近似 **发射率 ε(λ, θ)**（Kirchhoff 定律，
  局域热平衡，非偏振平均或指定偏振）。
- 二维等效结构（1D 光栅）仅在 TE/TM 偏振、平面入射时使用，并需要在脚本中说明。
- 表面氧化层、粗糙度、温度依赖的色散等效应默认 **未包含**，需在具体研究中加入。

## 目录结构
```
meep_sim/
├── README.md
├── requirements.txt
├── .gitignore
├── src/                  # 可复用模块（不要在 scripts/ 中复制粘贴）
│   ├── geometry.py       # 微结构几何（光栅 / 柱 / 坑 / 多层）
│   ├── materials.py      # 金属色散模型 + 单位换算
│   ├── simulation.py     # Meep Simulation 装配、源、监视器、运行
│   ├── postprocess.py    # R/T/A → ε(λ,θ)、角谱、归一化
│   └── io_utils.py       # 配置加载、CSV/PNG 输出、日志
├── scripts/              # 一次性可运行的研究脚本（每个脚本头部声明研究目的）
├── configs/              # YAML/JSON 参数文件（每次运行存档一份到 results/）
├── data/
│   ├── raw/              # 原始 Meep 输出（HDF5、flux 数据）
│   └── processed/        # 整理后的 CSV / npz
├── results/
│   ├── figures/          # PNG 图（带轴、单位、图例、标题）
│   ├── tables/           # 汇总表
│   └── reports/          # Markdown 研究报告
├── logs/                 # 脚本运行日志
└── tests/                # 模块单元测试（pytest）
```

## 运行规范
每个 `scripts/*.py` 必须：
1. 顶部注释写清楚 **研究目的 / 输入 / 输出 / 适用范围 / 物理假设**；
2. 能独立运行：`python scripts/xxx.py --config configs/xxx.yaml`；
3. 输出至少 **CSV（数据）+ PNG（图）+ 日志**；
4. 对关键数值做自检（能量守恒 R+T+A≈1、单位一致、参考解对比）；
5. 输出文件名包含时间戳或配置哈希，便于追溯。
